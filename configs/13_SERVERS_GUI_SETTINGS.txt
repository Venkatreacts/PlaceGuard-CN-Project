=====================================================================
 SMART INTERVIEW HALL (IoT)
=====================================================================
Devices (End Devices > Home / Components): RFID Reader (rename RFID-READER),
Door (HALL-DOOR), Siren (ALARM-SIREN), 2 x RFID Card (CARD-1001, CARD-2002).
For RFID-READER, HALL-DOOR, ALARM-SIREN:
  - If the device has no Ethernet port: Advanced > I/O Config > Network Adapter
    = PT-IOT-NM-1CFE.  Cable it to ACC-INTERVIEW Fa0/11, Fa0/12, Fa0/13.
  - Config > Settings > IP: DHCP.  IoT Server: Remote Server
    Server address 10.10.60.10, user pgadmin, password Iot@2026 > Connect.
RFID cards: open card > Attributes/Config > Card ID = 1001 (CARD-1001) and 2002 (CARD-2002).
On PLC-OFFICER browser http://10.10.60.10 (login pgadmin) > Conditions > Add:
  1. ACCESS-GRANTED : IF RFID-READER Card ID = 1001
        THEN set RFID-READER Status = Valid ; HALL-DOOR Lock = Unlock ; ALARM-SIREN On = false
  2. ACCESS-DENIED  : IF RFID-READER Card ID = 2002   (use "!= 1001" if your PT offers it)
        THEN set RFID-READER Status = Invalid ; HALL-DOOR Lock = Lock ; ALARM-SIREN On = true
Demo: hold ALT and drag a card onto the reader (or move it next to the reader).
